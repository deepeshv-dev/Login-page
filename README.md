# 🔐 Responsive Login Page

## 📌 Project Overview
A modern and professional Login Page designed using HTML and CSS. The page features a clean user interface with a responsive layout that adapts to both desktop and mobile devices.

## ✨ Features
- Modern and clean UI design
- Email address input field
- Password input field
- Sign In button
- Forgot Password option
- Create Account link
- Responsive desktop and mobile layout
- Interactive input field styling

## 🛠️ Technologies Used
- HTML5
- CSS3

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. View the responsive Login Page.
